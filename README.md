# BB-Fitness-Legal

Public legal documents for [Buzzer Beater Fitness](https://apps.apple.com/app/id6815524970), hosted via GitHub Pages. Kept as its own small public repo so the app's main source repo can stay private.

- [Privacy Policy](https://rhenze74.github.io/BB-Fitness-Legal/privacy-policy.html)

Source of truth for the privacy policy content lives in the main app repo at `Docs/legal/privacy-policy.html`; this repo holds the standalone, publicly-hosted copy. Update there first, then republish here.
